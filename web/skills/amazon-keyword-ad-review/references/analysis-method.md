# 证据与调价方法

- 广告每日竞价是基础bid，CPC是花费/点击的实际均价。用每日竞价的变化划分真实调价阶段，核对标注记账日期；标注“CPC+0.05”不证明实际CPC或bid已按该数改变。
- 合计曝光、点击、花费、订单、销售额后计算CTR、CVR、CPC、ACoS，不平均逐日比率。零分母记未知。核实币种、订单归因口径及数据截止；新活动30天窗口可能只有几天有效投放。
- 近7天和前7天用于方向，30天用于稳定性；另看每次实际调价前后窗口。样本少时报告点击/订单数和不确定性，避免因为1单制造强烈结论。
- naturalRankDate/spRankDate是实际观察日，snapshotDate是快照日期。按关键词+指标+真实观察日去重；冲突保留来源供核实。缺测不能前向填充后称为当天排名。0/缺失须依备份语义区分未上榜/无数据。
- 对照未调价的相似词、整体产品趋势、价格/促销/库存/季节变化。bid上涨与自然位变化仅是关联。广告位本身不等于自然流量收益；没有增量销售或对照证据，不宣称广告增量有效。
- 区分直接与间接订单/销售。间接订单多时需要购买ASIN→父体映射；不能将组合内其他产品销售认定为当前产品的推排名收益。关键词报表也不等于真实搜索词报告，广泛词尤其如此。

## 如何给具体金额

先核实最新实际基础bid、日期和调整策略/位置加价（无字段说明缺口），再比较历史不同bid阶段下点击、CPC、订单和有效排名。引用可比窗口和样本。优先在出现过有效成交/排名的价位附近提出可检验的幅度，而非统一±0.03/0.05。

盈利词可用 `允许CPC≈目标ACoS×每次点击销售额` 作经济边界，注明销售归属、样本和归因局限；这不是基础bid，禁止直接套入bid字段。排名词可在本次确认的试验损失内有条件测试，说明期望看到的真实自然位/点击/订单变化和停止条件。没有可靠bid或预算边界时，数值用null，行动说明写待核实/维持观察。

预算建议必须按产品上限汇总，防止多个词各花完整上限。活动共享预算不能按关键词预算重复加总。只有活动预算、日内花费、耗尽时间等证据才能判断预算限制；没有时只提出条件分配和需要补充的数据。65 CAD未确认周期前，不计算日预算。

日明细无法推断小时转化率。时段建议需要站点时区、小时曝光/点击/花费/订单、预算耗尽记录及归因说明，比较足够多周的同星期小时样本。数据不足明确暂不设置小时停投；可以报告星期差异作为线索，不能冒充小时结论。

## 周一与周四的连续复盘

本轮输出包含上轮建议、用户是否采纳、每日竞价是否验证已执行、执行日期、执行后新观察。未执行不要评价效果；无法验证写未知。周四有时只有2–3天数据，先做异常检查；符合止损条件才提前改动，否则给继续观察条件，避免把归因延迟误判为失败。
