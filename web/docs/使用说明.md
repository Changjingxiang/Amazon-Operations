# 关键词排名每日跟进网页版 v2.1

## 打开方式

双击 `index.html` 或 `打开网页版.cmd`，推荐使用最新版 Chrome 或 Edge。

网页版保留看板、自然矩阵、SP 矩阵、对比矩阵、ABA 月榜、历史记录、关注词排序、自然/SP 双矩阵标注、型号新增、产品删除、自定义产品图片、竞品抽屉对比、列宽调整和日期筛选。看板顶部新增“自然/SP对比总览”，展示当前日期的上榜关系、第一页关键词数、排名页分布和差值分布，并可通过“详情”按钮跳转到对比矩阵的“自然领先”或“SP领先”区域。对比矩阵按当前日期分为两个区域，每个日期下并列显示自然和 SP 排名，排名下方用 ①/②/③ 标记所在页，并继续以红色/绿色表示相比前一天上升/下降。ABA 趋势图在有去年数据时会追加去年同日及随后两个月的虚线参考。

## 数据保存

- 初次打开会载入 v2.0 随包附带的完整数据（6 个型号、约 3.5 万条历史记录）。
- 后续修改保存在当前浏览器的 IndexedDB 中，不会改动桌面版原文件。
- 点击左侧“工具文件夹”会打开“网页版数据管理”，可导出/导入 JSON 备份、下载原始 Excel，或恢复初始数据。
- 浏览器隐私模式、清理站点数据或更换浏览器可能清除本地数据，请定期导出备份。

## 产品、父体 ASIN 与图标管理

- 在“设置 → 产品管理”中修改父体 ASIN：在对应产品卡片的“修改父体 ASIN”输入框中输入新的 10 位 ASIN（格式 `B0XXXXXXXX`），点击“保存 ASIN”。保存后页面会自动刷新；原有历史、关注词、单元格标注和产品图标都会保留，旧 ASIN 报表也会继续匹配到该产品。
- 在“设置 → 产品管理”中删除产品：先点击左侧“第一次确定删除”，确认提示后再点击右侧“第二次确定删除”。删除只清理本地该产品的历史、关注词、标注和图标配置，不删除源报表文件。
- 点击左侧产品图标可选择内置服装图标，或点击“自定义图片”从电脑上传 PNG/JPG/GIF/WEBP/BMP（不超过 5 MB）。

## 竞品设置与对比

- 打开“设置 → 竞品设置”，选择归属的自有产品，填写竞品名称、父体 ASIN 和国家后点击“添加竞品”。同一个竞品 ASIN 不能重复登记。
- 竞品沿用自有产品的 SIF 自动导入和本地 Excel 导入方式：顶部“一键导入全部产品”会同时处理已登记的自有产品和竞品；报表按父体 ASIN 自动归档，历史数据保存在浏览器 IndexedDB。
- 左侧每个自有产品右侧的 28×28 圆形下拉箭头可展开竞品层级；竞品会缩进显示并保留“竞品”标识。点击竞品后，右侧继续使用与自有产品完全相同的看板、自然矩阵、SP 矩阵、ABA 月榜和历史页面，只切换到竞品数据。
- 看板、自然矩阵、SP 矩阵的关键词旁都有“竞品”按钮，点击可在抽屉中对比自身与竞品的自然排名、SP 排名、周 ABA、周搜索量、流量排名和状态。自然矩阵和 SP 矩阵的排名数字单元格悬停时，会显示同关键词、同日期的竞品排名和自有产品标注气泡。
- 删除竞品只会删除该竞品在浏览器中的配置和历史，不会删除电脑上的原始报表；删除前会弹出确认提示。

## 导入每日报表

产品国家在“设置 → 产品管理”中单独保存（美国、德国、英国、日本、加拿大、法国、西班牙、意大利共 8 个站点）。网页包附带的 SIF 扩展桥接层会按每个产品的国家打开对应反查地址，并自动点击“流量词”右侧的下载图标。“自动导入今日报表”和“一键导入全部产品”都严格先完成全部自有产品，再开始全部竞品；每个阶段按列表顺序执行，不交叉并发。下载字节回到网页后会立即校验父体 ASIN 并自动归档到对应产品，不再要求确认或手动选择文件。

首次使用需按扩展包 README 加载 `sif-batch-reverse-downloader`，并在扩展详情中打开“允许访问文件网址”（若通过 `http://localhost` 提供网页则无需此开关）。扩展仍会把文件保存到 Downloads 作为备份。若未安装扩展，两个批量入口都会提示先安装扩展；左侧“本地导入”仍保留原本的手动 Excel 导入逻辑。

旧版受保护的 `asinKeywords_*.xlsx` 仍无法由普通浏览器解析；这些文件的既有历史已经包含在初始数据中。

## 导入月 ABA

- 打开“设置”，在“月 ABA CSV 导入”中选择国家、年份、月份和对应的月度 CSV 文件，再点击“导入月 ABA 文件”。CSV 的“搜索词”按关键词使用，“搜索频率排名”按 ABA 排名使用。
- 同一国家和月份再次导入会先提示确认，然后覆盖该月份的旧数据；已导入月份和词数会显示在设置中。数据和 JSON 备份一起保存在浏览器 IndexedDB，不会修改原始 CSV。
- ABA 月榜显示“去年ABA排名环比趋势”：使用去年同月与去年下一个月的 ABA CSV 排名进行比较。排名数字越小越好；缺少任一月份数据时显示“—”，相同则显示“持平”。鼠标悬停可查看参与比较的排名数值。

## 浏览器与桌面版差异

- “打开跟进表”在网页版中会下载随包附带的原始 Excel。
- “打开源文件夹”在网页版中会弹出报表选择框。
- 网页版的“自动导入今日报表”和“一键导入全部产品”通过本地 SIF 扩展完成对应国家的页面打开、下载和报表回传；网页不会读取或修改 Downloads 文件夹，也不会修改 SIF 账号内容。
- 窗口最大化按钮改为进入/退出浏览器全屏；最小化和关闭由浏览器自身控制。
- 网页不能直接写回桌面文件夹，因此数据通过 IndexedDB 保存，并通过 JSON 备份迁移。
