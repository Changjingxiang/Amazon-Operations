# 新手指南与插件安装

## 打开软件

完整解压软件 ZIP 后，双击「打开网页版.cmd」或 index.html。推荐使用 Chrome / Edge。

首次加载完成后会显示欢迎页。点击「开始引导」查看 18 步场景教学，也可以「暂时跳过」。之后不会每次启动都弹出；需要重看时，点击右上角「使用指南」。中途退出后可以从目录继续上次的步骤；专题按钮直接带你进入对应页面。

教学会切换到看板、自然矩阵、SP矩阵、对比矩阵、趋势页、ABA月榜和历史记录，并打开对应的关注词表单、设置区域与工具文件夹。悬停课程会展示真实的趋势/详情浮窗，标注课程会打开只读的标注框示例。示例不保存，不替你导入报表、修改关注或写入标注；关闭后恢复原来的页签、筛选和滚动位置。

## 添加尚未有流量的词

进入「看板 → 管理关注词」，在新增关键词框中每行填写一个词，点击「保存并同步」。不要求该词已经出现在产品流量报表中；没有当天数据时会显示「本日报表未出现」等缺失提示。拖动左侧手柄可以调整关注词顺序。放大看板后也可正常打开管理关注词。

## 悬停与标注

- 看板关键词：悬停显示趋势预览，双击进入完整趋势页。
- 自然矩阵关键词：悬停显示 ABA 趋势对照。
- 自然/SP 排名格：悬停查看当天详情及已有标注；有关联数据时可查看竞品表现。
- 点击自然/SP 排名格填写标注；Enter 保存、Shift + Enter 换行、Esc 取消，点击编辑框外也会保存。保存后蓝色折角表示有标注，再次点击可编辑或清除。
- ABA月榜关键词：悬停查看月度热度趋势。

## 下载插件

两个入口都可以下载与软件配套的 SIF 在线版扩展 ZIP：

- 右上角「使用指南 → 下载插件 ZIP」。
- 右上角「工具文件夹 → 下载 SIF 在线版扩展」。

下载完成后右键 ZIP，选择「全部解压」，把插件文件夹保存在固定位置。也可直接使用软件包内的 sif-batch-reverse-downloader 文件夹。

## Chrome / Edge 安装

1. Chrome 地址栏输入 chrome://extensions/；Edge 输入 edge://extensions/。
2. Chrome 开启「开发者模式」，点击「加载已解压的扩展程序」；Edge 开启「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择包含 manifest.json 的 sif-batch-reverse-downloader 文件夹，不要选择 ZIP 或外层目录。
4. 双击本地 index.html 使用软件时，在插件「详情」中开启「允许访问文件网址」。通过 localhost 使用时不需要该开关。
5. 在同一浏览器、同一用户配置中打开 SIF 并登录。
6. 返回关键词软件，刷新页面，再从「使用指南 → 安装教程」进入最后一步，点击「检查插件连接」。也可以用目录中的「继续安装」返回上次步骤。

连接成功仅表示插件可以和当前软件通信，不代表 SIF 已登录或报表已下载。接下来可手动尝试「导入当前产品」（包含关联竞品）。安装完成后不要删除或移动插件文件夹。

未检测到连接时，检查：插件是否启用 → 是否安装在当前浏览器配置中 → 本地网页权限是否开启 → 当前软件是否已刷新。连接正常但导入失败时，检查 SIF 登录和浏览器是否拦截多文件下载。

## 从旧版迁移

先在旧版「工具文件夹」导出 JSON 备份，然后打开新版。若未自动显示原数据，用新版「工具文件夹 → 导入数据备份」恢复。软件随包的初始数据不是你浏览器内最近更新的数据；请保留旧版和导出的备份，核对新版的产品、日期、关注词与标注后再继续使用。

新手教学进度仅存于当前浏览器，与产品数据和备份分开保存。更换浏览器或清理站点数据后可能重新出现首次引导。
