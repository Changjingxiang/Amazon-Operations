# 关键词排名每日跟进网页版 v2.1 · AI 分析

现在可以在原网页版的商品页或关键词行点击“AI 分析”。排名、标注和筛选继续使用原网页数据，不必迁移到独立增强窗口。

## 首次安装（Windows 10/11 x64，Chrome / Edge）

1. **解压完整压缩包**。把随包的 `AI本机连接器` 文件夹放到固定位置。不要只复制其中一个 EXE，也不要从压缩包内直接运行。
2. 双击 `AI本机连接器/KeywordRankAIConnector.exe`，选择 **注册连接器**。仅注册当前 Windows 用户，不需要管理员权限。注册后不要移动此文件夹；移动后重新注册即可。
3. 打开浏览器的扩展管理：Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
4. 开启“开发者模式”，点击 **加载已解压的扩展**，选择随包的 `AI浏览器扩展` 文件夹。
5. 如果双击 HTML 使用网页版，在此扩展的“详情”中开启 **允许访问文件网址**。这项设置需要你在浏览器中手动开启。
6. 回到关键词网页，点击浏览器工具栏的 **关键词 AI 安全连接 → 连接当前页面**。核对本机弹窗中的页面地址，只允许自己信任的关键词网页。
7. 在网页打开 **AI 分析 → 安全设置**。在弹出的专用本机窗口输入 HTTPS API 地址、模型和自己的密钥。勾选 Windows 加密保存后，下次无需重复输入；也可仅本次连接使用。

需要 Windows 自带的 .NET Framework 4.x（Windows 10/11 通常已有）。无需另装 Node.js。未配置代码签名证书。

## 日常使用

1. 打开原关键词网页，在扩展中连接当前页面。每次刷新、关闭页面或重启浏览器后需重新连接。
2. 商品页点“AI 分析”，或关键词旁点“AI”。分析直接读取网页当前数据。
3. 广告报表页可导入 SP 搜索词、投放及推广商品 CSV/XLSX。先核对映射、站点、币种、时区、账户类型和归因窗口，再保存。
4. 选择分析期间、广告组及关键词，检查数据并查看实际发送预览。
5. 勾选网页确认后开始分析；本机还会显示平台和模型供你确认发送。这一步用于防止网页静默调用、消耗 API 额度。
6. 报告、证据和历史都在网页中查看。可以取消；失败后可继续操作，只由你手动重试。

一次仅连接一个网页。使用连接器前，请关闭此前的独立 AI 增强窗口，并断开其他 Chrome / Edge 页面中的 AI 连接。SIF 原扩展与导入功能照常使用。

## 原数据与更新

### 领星广告报表与本次修复

- 按表头识别领星关键词广告报表，建议选择“SP 投放报表”；不依据下载文件名判断来源。导入前核对仅含 SP、站点、币种、时区和账户归因口径。
- 支持“广告活动、广告组、关键词、匹配方式、点击、广告订单、广告销售额”等列。直接/间接销售额暂不自动映射为 Amazon 推广/关联商品销售额。
- 对标准解析器无法读取的 XLSX，在 Windows 本机调用已安装的 WPS 兼容读取，只读打开，禁用宏，不更新外部链接、不保存原文件。未安装 WPS 或读取失败时，可用 WPS 另存为 CSV（UTF-8）再导入。
- Sif 批量反查扩展 1.1.3 仅处理来源明确属于 `https://www.sif.com` 的下载；其他网站的十位数字、ASIN 或包含 sif.com 的文件名不会触发改名。
- 更新 Sif 扩展时，请停用旧的“ Sif ASIN 批量反查下载器”，加载新包中同名扩展文件夹；不要同时保留旧版本启用。AI 连接器也需注册新包中的版本，刷新网页后重新连接。无需重新输入已保存的密钥。

排名、ABA、标注仍由原网页版保存，连接器不会自动迁移或覆盖它们。连接器保存的广告、分析历史和密钥沿用 `%APPDATA%\KeywordRankAI`，因此此前独立 AI 增强版的广告、历史与加密设置可以继续使用。

首次切换到新解压路径前，建议先从旧网页导出 JSON 备份；浏览器对本地文件的存储隔离可能受路径影响。打开新页面后，如未看到原数据，通过原“工具文件夹”导入这份备份。不要用空种子覆盖旧网页数据。

## 安全边界

- 网页和扩展没有读取或保存 API 密钥的接口，密钥仅在本机专用窗口输入，由 Windows 加密保存。
- 不开放本地 HTTP / TCP 服务端口。浏览器 Native Messaging 经当前用户专属的 Windows 命名管道连接本机程序；首次页面配对、每次发送均需本机确认。
- 扩展只在你点击连接后注入当前页面，不自动读取其他页面。连接后的页面可读取本机广告报表及历史，因此不要连接不信任的网站。
- API 仅允许 HTTPS 公网目标，不向重定向目的地发送密钥；支持 OpenAI 兼容 Chat Completions。
- 发送前可查看平台、模型和完整请求。名称以代号处理，关键词和经营指标仍可能透露业务信息；第三方平台会收到这些数据及用于该平台的密钥。
- 原始 Excel、完整排名库、密钥和本地路径不发送给模型；模型不能修改广告或执行命令。
- 不设置公共密钥，不内置账号，不自动重试。测试连接也可能计费；取消已发送请求不保证免除平台计费。

## 连接失败

| 提示 / 情况 | 处理 |
| --- | --- |
| 找不到本机程序 | 先运行 KeywordRankAIConnector.exe 注册；确认完整文件夹仍在注册的位置。 |
| 无法连接本地 HTML | 在 AI 扩展详情开启“允许访问文件网址”。 |
| 已有页面连接 | 在扩展里先断开旧连接；关闭独立增强窗口。 |
| 页面刷新后断开 | 再次点击扩展“连接当前页面”。排名数据仍在网页中。 |
| 等待确认 / 长时间未响应 | 查看 Windows 的本机确认窗口；不需要等待时选择取消，再手动重试。 |
| API 不兼容 / 鉴权失败 | 核对完整接口、模型、密钥权限与额度。不要关闭 TLS 校验。 |

移除连接器时，再次运行 KeywordRankAIConnector.exe，选择“移除注册”，然后在浏览器删除 AI 扩展。此操作不删除已有业务数据或密钥；密钥可先通过安全设置清除。

## 分析口径和验证边界

沿用首版分析规则：ABA 搜索频率排名不当作搜索量；搜索词与投放词分别保留；搜索词报表仅覆盖有点击的词；卖家/供应商归因口径分别确认；不同币种和归因口径不直接汇总；广告组成绩不强行分给单一 ASIN。指标由本机计算，AI 解释仍需人工核查。

发布测试使用合成数据和模拟 API，没有上传你的真实经营数据。真实平台与实际 SP 导出报表仍需首次连接后核对。本版仅供手动分析，不接入广告账户或自动调价。
