# 每周广告关注词分析

每周一上午、周四下午各做一次：

1. 导出当前网页备份；从领星导出最近30天关键词每日广告数据（含每日竞价）。
2. 在 Agent 中调用「亚马逊关键词分析」，提供两类文件。Skill每次先让你确认各产品目标：ACoS、排名优先词/ABA口径、预算与周期、站点币种和时区。
3. Agent结合7天、30天、真实自然/SP排名日期与标注给出分析，交付经过格式校验的JSON。
4. 网页点「每周广告关注词分析」→导入Agent分析结果→核对产品/词匹配→确认导入。左侧切换产品查看各自建议。
5. 自然矩阵红角标表示有建议；双击单元格查看。勾选采纳后，该批次对应单元格出现紫框✓；不改变原有排名颜色和标注。取消勾选即可撤回采纳。
6. 下一轮再次导出网页备份，带上历史建议和采纳状态。周四核查周一实际执行情况，不把“采纳”自动当成已调价。

周一和周四各保留独立批次。同一格有多次报告时角标以最新批次为准，弹窗保留所有历史。角标使用报告数据截止前最近的矩阵日期，不补造排名记录。

## Skill安装

本包 `skills/amazon-keyword-ad-review` 是完整Skill目录，显示名为「亚马逊关键词分析」。复制到你的Codex skills目录后，在新任务中调用即可。已安装者更新整个目录，保留自己的其他Skill。

依赖：Agent负责分析；辅助数据整理需Python 3与openpyxl，格式校验需Node.js 18+。不需要广告API或付费接口。Skill安装后不会自动定时运行；按上述两次节奏手动导出并发起分析。

精确调价指基础竞价建议，不是承诺实际CPC。没有小时数据时不会猜测小时投放；没有预算/耗尽证据时不会认定预算不足。网页只保存建议及采纳，实际广告操作仍由你完成。
