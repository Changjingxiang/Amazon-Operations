# Amazon关键词每日跟进-v3.0.5

2026-10-09 更新：看板新增多条件排序，每项可独立升序或降序，并可调整优先级、删除或清除；放大看板后的筛选和排序面板可正常显示及操作。

点击「多条件排序」→「添加排序条件」，例如依次设置周ABA排名升序、SP排名降序、自然排名升序。前一条件数值相同才比较下一条件，修改即时生效。

关注词按关注管理的顺序置顶；缺失值排在对应条件的最后。按 Esc 先关闭筛选或排序面板，再按一次退出放大看板。

本次多选复制小改版仍为 v3.0.5：看板新增与其他矩阵相同的点选、拖选、Enter 复制功能，复制结果去重并每行一个。设置中的复制快捷键也支持看板。

选择和复制时，上方居中的独立行显示 5 帧透明 K 放大镜动图；复制成功切换为 5 帧 K 打勾动图和「复制成功」提示，播放 2 秒并淡出。两张动图合计 10 帧。自然、SP、对比和 ABA 矩阵同步增加相同反馈。图片不覆盖筛选、排序、关键词或其他按钮。

在多选模式中，Esc 先关闭筛选或排序面板，再退出多选，最后恢复放大看板。
