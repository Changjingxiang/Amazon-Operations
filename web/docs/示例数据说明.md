# Amazon关键词每日跟进-v3.0

首次使用的示例数据来源于 2026-09-22 的备份，只包含：

- 自有产品：L23M911薄夹克（B0C1YF9FWH）。
- 关联竞品：BGOWATU（B0D7HQDP6Y）、MAG 911（B0BVKGGWLY）、Rdruko（B0BZJ6FSQM）。

保留这四个产品的 43,453 条排名历史、相关关注词、标注和产品图片。其他自有产品与无关竞品不包含在初始数据中；共享竞品只关联 L23M911。

首次打开后可跟随新手指南，用这一组产品练习查看排名、悬停详情、管理关注词和标注。教学示例不会修改业务数据。点击左侧 L23M911 右侧箭头，可展开三个关联竞品。

月度 ABA 数据仅保留这些产品历史及关注列表涉及的关键词，原始排名数值不变。新增自己的产品后，请在设置中导入所需国家与月份的完整 ABA CSV。

「工具文件夹 → 下载示例参考 Excel」提供当前快照、关注词和标注的参考表。它不是 SIF 原始报表，也不是网页数据的保存位置。完整示例数据在 `data/Amazon关键词每日跟进-v3.0-示例数据.json`，可通过「导入数据备份」导入。

软件会优先读取当前浏览器中已经保存的数据，不会用示例覆盖已有数据。初次使用者请完整解压后打开「打开网页版.cmd」或 `index.html`。准备开始管理自己的产品时，通过「新增型号」添加自己的产品；不再需要示例后可在设置中删除示例产品。
