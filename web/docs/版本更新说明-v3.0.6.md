- 新增墨西哥站（MX）和澳大利亚站（AU），覆盖新增型号、产品国家设置、竞品设置和月 ABA CSV 导入。

升级前可导出 JSON 备份。沿用现有浏览器数据存储，无需重新创建已有产品。

## 2026-10-26 本地批量导入修复（软件版本仍为 v3.0.6）

- 减少内存占用：同一份数据的矩阵投影复用；批量任务只读取产品配置，不再为每份报表重建全部矩阵；每份 Excel 只解析一次，初始示例数据载入后释放临时引用。
- 配套 SIF 扩展更新为 v1.1.9：每份报表确认写入后才继续下一产品；页面刷新、关闭或失联时停止旧任务。失联检测最长约 90 秒，正在等待保存确认的报表设有 120 秒超时。
- 任务按页面会话和运行编号隔离，旧任务消息不会混入重试。自己产品阶段未完成时，竞品阶段显示“尚未启动”。
- 更新时先停止旧扩展任务，替换软件文件，并在 Chrome 扩展管理页重新加载 v1.1.9（确认“允许访问文件网址”开启），再打开 index.html。仅更新网页文件不能修复旧扩展继续运行的问题。
- 沿用 amazon-keyword-daily-v3 数据库，不删除历史记录。已下载但未写入的 Excel 可用“本地导入”补录。
