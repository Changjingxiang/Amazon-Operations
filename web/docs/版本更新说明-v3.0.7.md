# Amazon关键词每日跟进-v3.0.7

2026-11-03 · 关键词曝光指数与异动提醒

- 看板总览新增 ECharts 每日堆叠柱：自然为下方绿色，SP（常规）广告为上方红色。可查看近 7 / 30 / 90 天或全部历史；无报表日期保留空缺。
- 自然指数 = Σ（周搜索量 ÷ 自然排名^0.8）；SP 指数使用相同公式与 SP 排名。该自定义指数用于比较已监测关键词的曝光分量，不是 SIF 原始分、实际访客数或全市场份额。
- 统计完整历史日报中的关键词，不受前 1000、关注状态及表格搜索筛选影响。同词同日只取最后一次导入。
- 悬停显示自然 / SP / 综合得分和贡献 Top 5，附周搜索量、两类排名变化、两类得分及综合变化。Top 5 按今日与昨日较高的贡献选取，保留昨日重要而今日下降的词。
- 周搜索量缺失、排名缺失、排名日期未知、采集日期早于快照前一天或晚于快照日期时，不计入该渠道得分；仅明确的排名 0 记为未上榜。缺失不补零、不使用未来搜索量回填历史。图中展示有效搜索量覆盖数。
- 涨跌仅比较连续两天在同一渠道都有有效数据的同一组关键词。自然、SP、综合分别检查；零基数或缺少前一天时不计算百分比。柱高为当天全部有效词之和，因此可能与用于比较的词集合不同。
- 默认严格超过 ±20% 才公示。设置 → 曝光异动提醒可以保存 1–1000% 的整数阈值，刷新后仍保留；无超限项不弹异动窗。
- 上涨使用 K 竖大拇指，下跌使用 K 失落表情；单一方向居中、双方向左右显示。提供产品看板、自然矩阵及 SP 矩阵快捷入口。同一产品若不同分项涨跌方向不同，会分别列在两侧。
- 自有产品与竞品阶段仍严格顺序执行。全部成功并确认保存后只更新一次页面数据；异常或保存问题继续使用原有恢复面板。只有自有产品进入异动公示，竞品仍可查看其指数图。
- 本地日报导入同样支持异动公示。同样的快照内容在确认查看后不重复提醒；未读公示保存于本机，刷新后继续显示。
- 设置改为右侧抽屉，按功能区展开；大字标题下提供小字说明。保留表格快捷键、月 ABA 导入、共享竞品库和产品管理。

沿用原有 IndexedDB，不修改已有排名、ABA 与导入匹配算法。升级前可在旧版导出 JSON 备份；若新版没有自动显示旧数据，使用工具文件夹导入该备份。异动阈值是当前浏览器的本机偏好，不包含在业务 JSON 备份中。
