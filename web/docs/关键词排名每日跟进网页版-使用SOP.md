## 2. 使用前须知

1. 收到 ZIP 压缩包后，必须先完整解压，不能直接在压缩包内运行。
2. 必须保留整个软件文件夹，不能只复制 `index.html`。
3. 不同电脑、不同浏览器的数据相互独立，不会自动同步。
4. 网页版不会修改桌面版的 Excel、JSON 或每日源文件。
5. 清理浏览器数据、使用隐私模式、更换电脑或移动软件目录前，应先导出 JSON 备份。
6. 软件包内包含制作发布包时的初始业务数据。将软件发送给外部人员前，请确认这些数据允许共享。

## 3. 首次打开软件

### 3.1 解压发布包

1. 右键 ZIP 压缩包。
2. 选择“全部解压”或使用常见解压软件解压。
3. 将完整文件夹放在固定位置，例如桌面或文档目录。
4. 正式使用后不要随意移动、重命名或拆分文件夹。

### 3.2 启动软件

可使用以下任一方式：

- 双击 `打开网页版.cmd`；
- 双击 `index.html`，并选择 Edge 或 Chrome 打开。

首次打开时，网页会载入随包附带的完整 v2.0 数据。由于数据量较大，首次加载可能需要数秒，请不要连续刷新或关闭页面。

### 3.3 首次检查

打开后确认以下内容：

- 左侧能够看到产品型号列表；
- 页面顶部显示当前产品名称和父体 ASIN；
- “看板、自然矩阵、SP矩阵、ABA月榜、历史记录”五个页面可以切换；
- 产品图标和表格正常显示；
- 底部状态栏显示关键词数量和源文件数量。

## 4. 页面结构说明

### 4.1 左侧产品栏

用于切换不同产品型号，主要功能包括：

- 点击产品型号：切换当前查看产品；
- 点击产品图标：更换该产品的服装图标；
- 点击“新增型号”：登记新的产品型号；
- 点击“导入日志”：进入当前产品的历史记录页面；
- 点击“工具文件夹”：打开网页版数据管理；
- 点击“设置”：管理表格列宽、产品国家、父体 ASIN 和产品删除等设置。

### 4.2 设置与产品管理

#### 4.2.1 修改父体 ASIN（保留历史）

1. 打开“设置 → 产品管理”，找到要修改的产品卡片。
2. 在“修改父体 ASIN”输入框输入新的 10 位父体 ASIN，格式为 `B0XXXXXXXX`。
3. 点击“保存 ASIN”。网页会校验格式和重复 ASIN，成功后自动刷新。
4. 修改只替换产品的当前父体 ASIN；原历史记录、关注词、自然/SP 标注、ABA 数据及图标配置均保留。
5. 旧 ASIN 会作为历史别名保留，因此旧 ASIN 的报表仍能自动匹配到这个产品；以后新报表请使用新的父体 ASIN。

#### 4.2.2 导入去年月 ABA

1. 在“设置”顶部的“月 ABA CSV 导入”区域选择国家、年份、月份。
2. 选择对应的月度 ABA CSV 后点击“导入月 ABA 文件”。文件中的“搜索词”会作为关键词，“搜索频率排名”会作为 ABA 排名。
3. 同一国家和月份已有文件时，网页会要求确认覆盖；“已导入月份”会显示词数和文件名。

### 4.3 顶部操作区

| 功能 | 说明 |
|---|---|
| 日期选择 | 选择要查看的历史日期 |
| 刷新 | 重新读取当前浏览器中的本地数据 |
| 自动导入今日报表 | 通过扩展按设置的国家分阶段自动下载并回传：先完成全部自己产品，再完成全部竞品 |
| 本地导入 | 选择并导入一个或多个 Sif Excel 报表 |

### 4.4 功能页签

| 页签 | 主要用途 |
|---|---|
| 看板 | 查看当前日期的关键词、流量、自然排名、SP 排名及趋势 |
| 自然矩阵 | 按日期横向对比自然排名变化 |
| SP矩阵 | 按日期横向对比广告排名，并填写单元格标注 |
| ABA月榜 | 查看月度 ABA 排名、年内最高搜索量及点击转化率 |
| 历史记录 | 查看每日快照、写入数量和源文件记录 |

## 5. 每日标准操作流程

### 第一步：准备报表

1. 从数据来源导出当天的普通 Sif `.xlsx` 报表。
2. 确认文件名和报表内容对应正确的父体 ASIN。
3. 不需要将文件复制到网页版软件目录中。

> 旧版受保护的 `asinKeywords_*.xlsx` 无法由普通浏览器解析。此类文件的既有历史已经包含在初始数据中。

### 第二步：自动导入今日报表

1. 首次使用先加载随包提供的 `sif-batch-reverse-downloader` 扩展；Chrome/Edge 扩展详情中打开“允许访问文件网址”。
2. 打开网页版并切换到要更新的产品。
3. 如需修改站点，先进入“设置 → 产品管理”，在该产品右侧的“国家”下拉框中选择站点；国家代码会用于 SIF 的 `country` 参数。
4. 点击右上角“自动导入今日报表”或旁边的“一键导入全部产品”，都会按设置的国家分阶段处理：先完成全部自己产品，再完成全部竞品。
5. 扩展会在后台打开类似 `https://www.sif.com/reverse?country=CA&asin=父体ASIN&isListingSearch=false&trafficType=` 的结果页，完成反查后自动点击“流量词”右侧下载图标。
6. 下载完成后，网页自动接收同一份 XLSX、校验父体 ASIN 并写入当天历史；无需确认、无需手动选择文件。扩展仍会把文件保存到 Downloads 作为备份。
7. 如 SIF 要求登录，请先在同一浏览器登录；某个产品没有数据或失败时，网页和扩展弹窗会显示具体原因，可重试失败项。

纯网页本身不能跨域读取 SIF DOM、读取 `Authorization` 登录令牌或扫描 Downloads 文件夹，因此自动点击和报表回传由本地扩展完成；网页只负责展示、校验和保存导入结果。

### 第三步：本地导入报表

1. 点击右上角“本地导入”。
2. 在文件选择框中选择当天的一个或多个 `.xlsx` / `.xls` 文件。
3. 点击“打开”，等待导入完成提示。

导入规则：

- 软件根据父体 ASIN 自动匹配产品型号；
- 同一型号、同一日期的旧记录会被当天新报表替换；
- 已导入且文件指纹未变化的相同文件会自动跳过；
- 不属于任何现有型号的父体 ASIN 不会写入；
- 导入操作只写入当前浏览器，不会修改源 Excel 文件。

### 第四步：核对导入结果

导入完成后至少检查：

1. 顶部“最近数据”日期是否为当天；
2. 看板关键词数量是否合理；
3. 自然排名和 SP 排名是否显示；
4. 底部源文件数量是否更新；
5. “历史记录”中是否出现当天快照。

### 第五步：检查重点关键词

1. 进入“看板”。
2. 优先查看表格顶部的关注词。
3. 检查自然趋势和 SP 趋势。
4. 对异常排名、重点投放词或需要后续处理的词进行关注或标注。

### 第六步：备份数据

建议每天完成导入和标注后执行一次数据备份：

1. 点击左侧“工具文件夹”。
2. 点击“导出数据备份”。
3. 保存下载的 JSON 文件。
4. 建议按日期归档，例如：`关键词排名每日跟进数据_2026-08-28.json`。

## 6. 看板操作 SOP

### 6.1 查看数据

看板主要显示：

- 顶部“自然/SP对比总览”：共同上榜、自然领先、SP领先、仅自然上榜、仅 SP 上榜、第一页关键词数、排名页分布和差值分布；
- 关注状态；
- 流量排名；
- 关键词和翻译；
- 自然排名与 30 日趋势；
- SP 排名与 30 日趋势；
- 父体流量占比；
- 周 ABA 排名；
- 周搜索量；
- 数据状态。

颜色说明：

- 红色：排名上升；
- 绿色：排名下降；
- 灰色：未上榜；
- 黄色星标：已设为关注词。

“自然/SP对比总览”按当前日期的看板关键词计算，不包含趋势对比。差值分布只统计自然和 SP 都有排名的关键词；排名页分布中的 P1/P2/P3/P4+ 分别代表 1–10、11–20、21–30 和 31 名以后，未上榜单独列出。

### 6.2 看板排序

看板支持按周 ABA 和周搜索量进行升序或降序排列。无论选择哪种排序方式，关注词都会固定在表格顶部，并保持关注词管理中的自定义顺序。

### 6.3 设置或取消关注词

1. 找到目标关键词。
2. 点击该行左侧星标。
3. 黄色实心星表示已关注，空心星表示未关注。
4. 关注状态会同步到看板、自然矩阵、SP矩阵和 ABA 月榜。

## 7. 关注词管理 SOP

### 7.1 打开关注词管理

1. 进入“看板”。
2. 点击表格右上方“管理关注词”。
3. 右侧会打开关注词抽屉。

### 7.2 新增关注词

1. 在关键词输入框中输入关键词。
2. 可一次粘贴多行，也可使用逗号或分号分隔。
3. 如有需要，在备注中填写观察原因或运营说明。
4. 点击“设为关注”或保存按钮。

允许添加源报表中暂时不存在的词。此类词仍会保留在关注列表中，并显示为未上榜。

### 7.3 调整关注词顺序

可使用以下任一方式：

- 用鼠标或触屏拖动左侧六点手柄；
- 点击“上移”或“下移”；
- 键盘聚焦手柄后按空格抓取，再按 `↑` / `↓` 移动，按 `Esc` 取消。

调整完成后，点击“保存并同步”。关注词会按该顺序固定在各页面顶部。

### 7.4 删除关注词

在关注词抽屉中点击目标词右侧的删除按钮，然后保存。删除关注不会删除该关键词的历史排名记录。

## 8. 自然矩阵操作 SOP

1. 点击顶部“自然矩阵”。
2. 通过年份、月份标题展开或收起日期列。
3. 横向滚动查看不同日期的自然排名。
4. 通过单元格颜色判断排名变化。
5. 点击关键词左侧星标可设置或取消关注。
6. 拖动列头右侧分隔线可调整列宽。

矩阵中数字 `0` 表示当天未上榜。

---

## 9. SP矩阵与标注 SOP

### 9.1 查看 SP 排名

1. 点击顶部“SP矩阵”。
2. 通过年份、月份标题展开或收起日期列。
3. 横向滚动查看不同日期的 SP 排名。
4. 数字 `0` 表示当天未上榜。

### 9.2 新增或修改 SP 标注

1. 单击需要标注的 SP 排名单元格。
2. 输入广告出价、活动调整或其他备注。
3. 保存标注。
4. 已标注单元格显示为黑底白字，排名数字仍会保留。
5. 将鼠标移到标注单元格上可查看完整标注内容。
6. 再次单击或双击已标注单元格，可修改或清除标注。

建议标注格式保持统一，例如：

```text
大词 0.83-0.88；精确 1.13-1.16
```

## 10. ABA 月榜操作 SOP

1. 点击顶部“ABA月榜”。
2. 通过年份或月份标题展开、收起对应列。
3. 查看每个关键词的年内最高搜索量和最高点击转化率。
4. 查看每个月已导入 ABA CSV 中的排名；未导入月份显示“—”。
5. 将鼠标移到关键词上，查看以 ABA CSV 为准的今年与去年两种颜色 ABA 对照趋势图，各月点位会直接标出具体排名。
6. 点击左侧星标可设置或取消关注。

ABA 趋势浮层会自动靠近鼠标并避开窗口边缘。看板的关键词也支持同一悬停浮层；原始 ABA CSV 只读解析，不会被软件改写。

ABA 月榜表格还会显示“去年ABA排名环比趋势”。该趋势使用去年同月对比去年下一个月；排名越小越好，缺数据显示“—”，相同显示“持平”，悬停单元格可查看具体排名。

需要补充月度数据时，在“设置 → 月 ABA CSV 导入”选择国家、年份、月份和 CSV 文件；同一国家和月份再次导入会覆盖该月份的本地副本。ABA 月度排名和对照折线只使用这些 CSV，不参考日报中的周 ABA 排名。

## 11. 历史记录操作 SOP

1. 点击顶部“历史记录”，或点击左侧“导入日志”。
2. 查看历史快照日期、写入数量、关注词数量和源文件。
3. 点击“打开跟进表”可下载随发布包附带的原始 Excel。
4. 点击“打开源文件夹”时，网页版会弹出文件选择框，可直接选择新的报表进行导入。

> 网页无法像桌面软件一样直接打开电脑文件夹，因此“打开源文件夹”在网页版中改为选择并导入报表。

## 12. 新增型号 SOP

1. 点击左侧“新增型号”。
2. 输入产品名称。
3. 输入父体 ASIN。
4. 选择或填写站点。
5. 点击保存。
6. 新型号创建后，导入与该父体 ASIN 匹配的 Sif 报表。

父体 ASIN 要求：

- 必须以 `B0` 开头；
- 总长度为 10 位；
- 不能与现有型号重复。

新型号在首次导入匹配报表前，页面可能显示为空数据状态，这是正常现象。

## 13. 产品图标设置 SOP

1. 点击左侧产品型号前的服装图标。
2. 在图标选择器中选择合适的图标。
3. 保存后，左侧产品栏会立即更新。
4. 图标设置仅保存在当前浏览器中。

## 14. 表格列宽设置 SOP

### 调整单列宽度

1. 将鼠标移动到表格列头右侧边缘。
2. 按住并左右拖动。
3. 松开鼠标后，列宽会自动保存到当前浏览器。

### 恢复默认列宽

1. 点击左侧“设置”。
2. 点击“还原原表宽度”。
3. 所有表格恢复为 v2.0 默认宽度。

## 15. 数据备份、恢复与迁移 SOP

### 15.1 导出数据备份

1. 点击左侧“工具文件夹”。
2. 点击“导出数据备份”。
3. 浏览器会下载一个 JSON 文件。
4. 将文件保存到公司云盘、共享盘或指定备份目录。

JSON 备份包含：

- 产品型号；
- 全部历史排名；
- 关注词及顺序；
- SP 单元格标注；
- 产品图标设置；
- 已导入文件记录。

### 15.2 恢复数据备份

1. 点击左侧“工具文件夹”。
2. 点击“导入数据备份”。
3. 选择之前导出的 JSON 文件。
4. 导入成功后页面会自动重新加载。
5. 核对产品数量、最近数据日期和关注词。

导入备份会使用备份内容替换当前浏览器中的数据。操作前建议先导出当前数据。

### 15.3 将最新数据交给另一位使用者

1. 原使用者导出最新 JSON 备份。
2. 将网页版 ZIP 和最新 JSON 一起发送给新使用者。
3. 新使用者先解压并打开网页版。
4. 点击“工具文件夹”→“导入数据备份”。
5. 选择收到的 JSON 文件。

### 15.4 恢复发布包初始数据

1. 点击左侧“工具文件夹”。
2. 点击“恢复 v2.0 初始数据”。
3. 阅读覆盖提示并确认。
4. 页面重新加载后，数据恢复为发布包制作时的状态。

此操作会覆盖当前浏览器中的后续导入、关注词和标注，请务必提前导出备份。

## 17. 常见问题处理

### 17.1 双击后页面空白

处理步骤：

1. 确认已经完整解压；
2. 确认 `index.html`、`assets`、`data`、`vendor` 和 `browser-bridge.js` 在同一软件目录结构中；
3. 改用最新版 Edge 或 Chrome；
4. 不要单独复制或发送 `index.html`；
5. 重新解压原始发布包再打开。

### 17.2 图标显示为破损图片

原因通常是 `assets` 文件夹缺失、被改名或文件没有完整解压。重新完整解压发布包即可。

### 17.3 导入报表失败

依次检查：

1. 文件是否为普通 `.xlsx` / `.xls` 报表；
2. 报表是否为受保护旧格式；
3. 报表首行是否包含父体 ASIN 和导出日期；
4. 表头是否包含关键词、流量占比、自然排名、SP 排名、周 ABA 和周搜索量等必要字段；
5. 软件中是否已创建对应父体 ASIN 的型号；
6. 文件是否损坏或仍未下载完成。

### 17.4 导入后看不到当天数据

1. 点击“刷新”；
2. 检查顶部日期选择是否为最新日期；
3. 检查报表中的父体 ASIN 是否与当前型号一致；
4. 打开“历史记录”，确认当天是否出现快照；
5. 重新选择正确报表导入。

### 17.5 数据突然恢复或丢失

可能原因：

- 使用了隐私/无痕模式；
- 清理了浏览器站点数据；
- 更换了浏览器或电脑；
- 移动或重新解压到了新的目录；
- 使用了系统清理工具。

处理方法：点击“工具文件夹”→“导入数据备份”，恢复最近一次 JSON 备份。

### 17.6 同事打开后看不到我的最新修改

网页版不会自动同步。请先导出最新 JSON 备份，再让同事在自己的浏览器中导入该备份。

## 18. 数据安全规范

1. 发布包和 JSON 备份可能包含产品、关键词、广告标注及历史排名等业务数据。
2. 发送给外部人员前，应确认数据是否允许共享。
3. 不要通过公开链接传播包含业务数据的发布包。
4. JSON 备份应保存在公司批准的存储位置。
5. 离职、转岗或设备交接时，应按公司规范移交或清除数据。

## 20. 版本限制

- 网页版无法直接读写电脑上的桌面版 JSON、Excel 或文件夹；所有文件操作均通过选择文件或下载完成。
- 旧版受保护的 `asinKeywords_*.xlsx` 无法在普通浏览器中直接解析。
- 数据仅保存在当前浏览器中，不提供账号登录、云端同步或多人实时协作。
- 原桌面版的窗口最小化和关闭操作由浏览器自身控制；网页版最大化按钮用于进入或退出全屏。
