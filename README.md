# Amazon Operations

## 关键词排名每日跟进网页版 v2.0

网页版入口位于 [`outputs/关键词排名每日跟进网页版-v2.0/index.html`](outputs/关键词排名每日跟进网页版-v2.0/index.html)。

v2.0 在保留原有看板、自然矩阵、SP 矩阵、ABA 月榜和历史记录的基础上，支持：

- 自有产品与竞品分阶段自动导入（先全部自有产品，再全部竞品）；
- 竞品层级导航、统一详情页和竞品抽屉对比；
- 自然矩阵/SP 矩阵排名悬停竞品对比气泡；
- 父体 ASIN 修改并保留历史、自定义产品图片和双确认删除；
- 去年月 ABA 导入及同比、去年环比趋势。

首次使用请先阅读 [`使用说明.md`](outputs/关键词排名每日跟进网页版-v2.0/使用说明.md)，并按扩展目录中的 README 加载本地 SIF 桥接扩展。
