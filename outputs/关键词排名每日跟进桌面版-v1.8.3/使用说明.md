# 关键词排名每日跟进桌面版 v1.8.3

## 启动

双击 `关键词排名每日跟进软件-1.8.3-portable.exe`。软件需要放在已有的“关键词排名每日跟进工具”目录环境中，目录里应有跟进表和 `每日源文件` 文件夹；也可以通过环境变量 `KEYWORD_TOOL_ROOT` 指定该目录。

## 自动导入今日报表

1. 在“设置 → 产品管理”给每个产品选择国家（8 个 SIF 站点）。
2. 选中产品后点击右上角“自动导入今日报表”。
3. 软件会打开 SIF 对应国家页面，填写父体 ASIN，点击“反查流量词”、选择“父体”，然后直接下载并自动导入，不再弹出下载确认。

第一次使用若 SIF 要求登录，请在弹出的 SIF 窗口登录后，再点一次自动导入。详细流程见 `SIF自动导入说明.md`。

## 校验

- 文件：`关键词排名每日跟进软件-1.8.3-portable.exe`
- SHA-256：`424E0099F11D940996F3E1753CBAA5B78B79F107F75C3365AEB00CACB6AE31E6`
- 大小：80,795,802 bytes

软件不会删除源报表；下载文件会写入工具目录的“每日源文件”。“本地导入”按钮仍可扫描已存在的报表。
