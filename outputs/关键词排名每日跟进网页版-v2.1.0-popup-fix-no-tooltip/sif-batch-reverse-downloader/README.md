# Sif ASIN 批量反查下载器

一个本地 Chrome / Edge Manifest V3 扩展。它既可以单独输入最多 15 个 ASIN 批量下载，也可以作为“关键词排名每日跟进”网页版的桥接层：网页会把产品名称、父体 ASIN 和国家传给扩展，扩展在后台打开对应站点的 Sif 反查页，选择“父体”，点击“流量词”旁的下载图标，并把下载内容回传给网页自动导入。

## 安装

### Chrome

1. 解压下载包。
2. 打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `sif-batch-reverse-downloader` 文件夹。

### Edge

1. 解压下载包。
2. 打开 `edge://extensions/`。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的文件夹。

## 单独批量下载

1. 先打开任一 Sif 反查页并登录 Sif。
2. 点击浏览器工具栏中的扩展图标。
3. 输入 1–15 个 ASIN；支持换行、空格、中英文逗号和分号分隔。
4. 并发速度先用“3 个（推荐）”。点击“开始批量下载”。
5. 可以关闭弹窗；后台任务仍会继续。再次打开弹窗即可查看状态。

文件名会尽量规范为：

`Sif反查流量词_站点代码_ASIN_YYYY-MM-DD.xlsx`

若 Sif 实际返回 CSV / XLS / ZIP，会保留实际扩展名。重名文件由浏览器自动加序号，不覆盖旧文件。

## 网页版一键导入

1. 按上面的步骤加载扩展；在扩展详情中打开“允许访问文件网址”（网页版若通过 `http://localhost` 打开则不需要这一步）。
2. 打开 `关键词排名每日跟进网页版-v2.0/index.html`，在“设置 → 产品管理”中为每个产品选择国家。
3. 点击右上角“自动导入今日报表”或旁边的“一键导入全部产品”，都会先按顺序完成全部自己产品，再按顺序完成全部竞品；每个产品使用其设置的国家。
4. Sif 页面会在后台打开并自动点击下载，网页收到报表字节后立即校验父体 ASIN 并写入浏览器本地数据；不需要再次确认或手动选择 Downloads 文件。

扩展仍会把 XLSX 保存到 Chrome 的 Downloads 文件夹，网页导入使用的是同一份下载内容。若某个站点没有数据、登录失效或 Sif 改版，网页会显示对应产品的失败原因，可在扩展弹窗中重试失败项。

## 提速设计

- 直接打开带 ASIN 和站点代码的 Sif 反查结果地址，省去逐项人工输入与搜索。
- 默认 3 个后台标签页并行查询，最大可设为 5；真正触发下载的瞬间会依次执行，以确保文件与 ASIN 一一对应。
- 每个工作页只处理一个 ASIN，下载完成后自动关闭。
- 页面加载类失败会自动重试一次；下载结果不盲目重复点击，避免重复文件。

并发越高并不一定越快：如果 Sif 页面出现加载超时，把并发从 5 降到 3 或 2。

## 常见问题

### 提示“未检测到下载”

Chrome / Edge 可能拦截同一网站连续下载多个文件。点击地址栏右侧的下载拦截图标，允许 `www.sif.com` 自动下载多个文件，再在扩展中点击“重试失败项”。

同时建议关闭浏览器设置中的“下载前询问每个文件的保存位置”，否则 15 个文件会逐个弹出保存窗口。

### 提示“尚未登录”

在同一个浏览器配置中打开 Sif 并完成登录，然后重试。扩展不会读取或保存你的账号密码。

### 提示“Sif 页面可能已改版”

扩展使用了当前页面的稳定结构：

- 父体卡片：`.single_variant_wrap.pasin_item`
- 下载入口：`#title_top_color_pad .downloadPolorBtn`

如果 Sif 改版，需要更新 `content.js` 中的定位规则。

## 权限与数据

- `www.sif.com`：只在 Sif 反查页面执行自动点击和报表 Blob 回传。
- `file:///*`、`http://localhost/*`、`http://127.0.0.1/*`：只用于与关键词排名网页版交换批量任务和报表内容。
- `tabs` / `scripting`：创建和控制后台工作页。
- `downloads`：识别下载结果并规范文件名。
- `storage`：在本机保存 ASIN 草稿和任务进度。

ASIN 和任务状态只保存在浏览器本地；扩展不包含第三方统计、广告或远程代码。
