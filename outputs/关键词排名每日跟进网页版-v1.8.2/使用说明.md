# 关键词排名每日跟进网页版 v1.8.2

## 打开方式

双击 `index.html` 或 `打开网页版.cmd`，推荐使用最新版 Chrome 或 Edge。

网页版保留看板、自然矩阵、SP 矩阵、ABA 月榜、历史记录、关注词排序、自然/SP 双矩阵标注、型号新增、产品删除、自定义产品图片、列宽调整和日期筛选。ABA 趋势图在有去年数据时会追加去年同日及随后两个月的虚线参考。

## 数据保存

- 初次打开会载入 v1.8.2 当前的完整数据（6 个型号、约 3.5 万条历史记录）。
- 后续修改保存在当前浏览器的 IndexedDB 中，不会改动桌面版原文件。
- 点击左侧“工具文件夹”会打开“网页版数据管理”，可导出/导入 JSON 备份、下载原始 Excel，或恢复初始数据。
- 浏览器隐私模式、清理站点数据或更换浏览器可能清除本地数据，请定期导出备份。

## 产品、父体 ASIN 与图标管理

- 在“设置 → 产品管理”中修改父体 ASIN：在对应产品卡片的“修改父体 ASIN”输入框中输入新的 10 位 ASIN（格式 `B0XXXXXXXX`），点击“保存 ASIN”。保存后页面会自动刷新；原有历史、关注词、单元格标注和产品图标都会保留，旧 ASIN 报表也会继续匹配到该产品。
- 在“设置 → 产品管理”中删除产品：先点击左侧“第一次确定删除”，确认提示后再点击右侧“第二次确定删除”。删除只清理本地该产品的历史、关注词、标注和图标配置，不删除源报表文件。
- 点击左侧产品图标可选择内置服装图标，或点击“自定义图片”从电脑上传 PNG/JPG/GIF/WEBP/BMP（不超过 5 MB）。

## 导入每日报表

产品国家在“设置 → 产品管理”中单独保存（美国、德国、英国、日本、加拿大、法国、西班牙、意大利共 8 个站点）。网页包附带的 SIF 扩展桥接层会按每个产品的国家打开对应反查地址，并自动点击“流量词”右侧的下载图标。点击右上角“自动导入今日报表”处理当前产品，点击旁边的“一键导入全部产品”可一次处理所有已登记产品；下载字节回到网页后会立即校验父体 ASIN 并导入当前产品，不再要求确认或手动选择文件。

首次使用需按扩展包 README 加载 `sif-batch-reverse-downloader`，并在扩展详情中打开“允许访问文件网址”（若通过 `http://localhost` 提供网页则无需此开关）。扩展仍会把文件保存到 Downloads 作为备份。若未安装扩展，单个“自动导入今日报表”会回退到原来的 SIF 页面加文件选择流程；“一键导入全部产品”会提示先安装扩展。

旧版受保护的 `asinKeywords_*.xlsx` 仍无法由普通浏览器解析；这些文件的既有历史已经包含在初始数据中。

## 导入去年月 ABA

- 打开“设置”，在“去年月 ABA 导入”中选择国家、年份、月份和对应的月度 CSV 文件，再点击“导入月 ABA 文件”。CSV 的“搜索词”按关键词使用，“搜索频率排名”按 ABA 排名使用。
- 同一国家和月份再次导入会先提示确认，然后覆盖该月份的旧数据；已导入月份和词数会显示在设置中。数据和 JSON 备份一起保存在浏览器 IndexedDB，不会修改原始 CSV。
- ABA 月榜新增“ABA排名同比趋势”和“去年ABA排名环比趋势”两列：前者将本月周 ABA 排名中位数与去年同月比较，后者将去年同月与去年下一个月比较。排名数字越小越好；缺少任一月份数据时显示“—”，相同则显示“持平”。鼠标悬停可查看参与比较的排名数值。

## 浏览器与桌面版差异

- “打开跟进表”在网页版中会下载随包附带的原始 Excel。
- “打开源文件夹”在网页版中会弹出报表选择框。
- 网页版的“自动导入今日报表”和“一键导入全部产品”通过本地 SIF 扩展完成对应国家的页面打开、下载和报表回传；网页不会读取或修改 Downloads 文件夹，也不会修改 SIF 账号内容。
- 窗口最大化按钮改为进入/退出浏览器全屏；最小化和关闭由浏览器自身控制。
- 网页不能直接写回桌面文件夹，因此数据通过 IndexedDB 保存，并通过 JSON 备份迁移。
