# Amazon关键词每日跟进 v3.0.3 · 当前数据 Excel 导出

“工具文件夹 → 导出当前 Excel”和“历史记录 → 导出当前 Excel”现在会根据此浏览器已保存的数据生成工作簿，不再下载固定示例表。

工作簿按用途分 Sheet：产品与竞品、当前看板、按年拆分的自然/SP/对比矩阵、ABA 月榜与同月对比、ABA 原始月度记录、关注词、排名历史、单元格标注、导入记录、广告分析及产品图片。图片 Sheet 会嵌入当前图和历史图；空排名留空，不作为 0。第一个 Sheet 说明数据范围，第二个 Sheet 提供目录。

Excel 用于查看和分析。换浏览器或换电脑迁移数据仍应使用 JSON 备份。

下载 `keyword-rank-web-v3.0.3.zip` 后全部解压，再双击 `打开网页版.cmd`。
