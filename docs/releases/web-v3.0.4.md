# Amazon关键词每日跟进-v3.0.4

2026-09-28 发布。对比矩阵新增底部横向日期滚动条；日期之间的分隔线更加清楚，自然排名使用深蓝色数字，SP 排名使用紫色数字。排名上升或下降时显示红绿箭头，持平、新排名或无记录时不显示状态小标。

悬停自然/SP单元格可查看当天两种排名、比较日期和已有标注。页码从导入报表“自然排名详情”和“SP(常规)排名详情”中 `p` 后的数字读取，例如 `p3-r2` 显示 P3。没有排名或未保存排名详情时，矩阵不显示页码占位符。旧版导入的原始报表再次选择导入时会补读一次详情。
