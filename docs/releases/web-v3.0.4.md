## 2026-10-01 SIF 自动导入小修复

- 自然、SP 和对比矩阵按各产品实际导入日期判断默认月份：最新月份不足15个不同日期时，同时显示上个月和最新月份；达到15个日期后只显示最新月份。支持跨年，手动选月优先。

- 软件整合 SIF 扩展 v1.1.7；软件内插件下载入口与随包插件目录使用同一版本。
- SIF 上方父体概览异常时，确认目标 ASIN、父体提示和下方词表后继续下载；下载超时从下载步骤开始计时。
- 「导入当前产品」处理当前产品及关联竞品，「导入全部产品」处理所有产品；均先完成自有产品，再处理竞品。
- 支持本地网页版与 GPT 站点。已安装插件需要更新并重新加载；在线版允许访问本站，本地版开启“允许访问文件网址”，然后刷新软件。
- 自动检查与构建通过，真实 SIF 下载仍依赖用户浏览器中的登录与插件权限。

2026-09-28 发布。对比矩阵新增底部横向日期滚动条；日期之间的分隔线更加清楚，自然排名使用深蓝色数字，SP 排名使用紫色数字。排名上升或下降时显示红绿箭头，持平、新排名或无记录时不显示状态小标。

悬停自然/SP单元格可查看当天两种排名、比较日期和已有标注。页码从导入报表“自然排名详情”和“SP(常规)排名详情”中 `p` 后的数字读取，例如 `p3-r2` 显示 P3。没有排名或未保存排名详情时，矩阵不显示页码占位符。旧版导入的原始报表再次选择导入时会补读一次详情。
