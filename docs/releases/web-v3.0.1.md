# Amazon关键词每日跟进 v3.0.1 · 产品图片增强

左侧产品图悬停显示渐入预览；双击预览平滑放大到屏幕中央。当前图与旧图叠放，点击历史图仅查看，不改变当前图。底部可选内置简略图标或上传自定义图片。

使用：下载 `keyword-rank-web-v3.0.1.zip`，全部解压，再双击 `打开网页版.cmd`。不需要安装 Node.js。

验证：React/Vite 构建和实际浏览器交互检查通过，包括悬停预览、双击放大、上传图片、刷新后历史保留、历史图只读查看，以及 1100×720 窗口布局。
