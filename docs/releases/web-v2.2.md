# 关键词排名每日跟进网页版-v2.2

左侧自有产品和竞品名称现在支持双击打开对应站点的亚马逊商品页面，并在悬停时显示“双击进入商品页面”。单击仍切换软件内的产品，当前矩阵页签保持不变。

本版基于 v2.1 导入结果修复版，保留原有标注、数据持久化和批量导入结果功能。

## 下载与使用

下载发布页中的 **关键词排名每日跟进网页版-v2.2.zip**（下载文件名为 `keyword-rank-web-v2.2.zip`），全部解压后进入 `关键词排名每日跟进网页版-v2.2` 文件夹，双击 `打开网页版.cmd`，使用 Chrome 或 Edge 打开。无需安装 Node.js、Python 或 Codex。

升级前请先从旧版导出 JSON 备份；若新版未显示最新数据，再导入备份。GitHub 的 Code → Download ZIP 下载的是源码。
