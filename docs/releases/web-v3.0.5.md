# Amazon关键词每日跟进-v3.0.5

2026-10-09 更新。

- 看板支持按优先级组合多个排序条件：周ABA排名、SP排名、自然排名和周搜索量，各条件独立设置升序或降序。
- 前一条件数值相同才比较下一条件；条件可添加、删除及上下移动，清除后恢复原有流量顺序。关注词保持置顶及原有人工顺序，缺失值在对应条件中始终排在最后。
- 修复放大看板盖住筛选面板的问题；筛选与排序弹层使用统一的层级，Esc 先关闭当前弹层，再退出放大看板。
- 多选复制小改版：看板复用矩阵的点选、拖选、Enter 复制及自定义快捷键，关键词去重后每行一个。自然、SP、对比及 ABA 矩阵同步显示复制反馈。
- 选择和复制过程中显示 5 帧透明 K 放大镜动图；成功后显示 5 帧 K 打勾动图及「复制成功」，播放 2 秒并淡出。两张动图合计 10 帧，反馈放在工具栏下方的独立居中行，不覆盖按钮或表格。
- 多选模式中的 Esc 先关闭筛选或排序面板，再退出多选，最后恢复放大看板。

使用方法：完整解压后双击「打开网页版.cmd」或在 Chrome/Edge 中打开 `index.html`。
