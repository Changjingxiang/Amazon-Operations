# 关键词排名每日跟进 · AI 增强版 v2.1

这是独立的 Windows 10/11 x64 本机程序，沿用网页版界面。无需安装 Node.js，也不需要运行本地 HTTP 服务。原网页版仍可独立使用。

## 第一次使用

1. 解压发行包，运行 `keyword-rank-ai-v2.1.exe`。
2. 在原网页版的“工具文件夹”中导出 JSON 数据备份。在增强版首页选择“导入网页版 JSON 备份”。导入会检查结构并保存增强版原数据的恢复副本，不修改原网页版的数据。
3. 商品页点击“AI 分析”，或点击关键词旁的“AI”。通过“安全设置”填写平台 HTTPS API 地址、模型名称和你自己的密钥。可选择仅本次会话，或使用 Windows 系统加密保存。
4. 先用“仅测试连接”确认接口。测试只发送固定文本，也可能产生少量费用。
5. 在“广告报表”导入 SP 报表，核对账户、站点、币种、时区、生成日期与字段映射，再确认保存。
6. 选择分析期间、关键词和广告组，点击“检查数据与发送预览”。核对平台域名和实际请求正文，勾选确认后发送。

增强版首页也能直接进入广告导入和分析，不强制先导入排名。SIF 浏览器扩展继续在原网页版中使用；增强版可手动导入已下载报表或更新 JSON 备份。

## 支持的数据

- SP 搜索词、投放和推广商品报表，CSV / XLSX，中英文常用列名和统一报表列名。未知列名必须手动映射。
- 每个文件一个数据工作表，第一行为列名；最多 20 MB、50,000 条记录、100 列。优先导出每日报表。
- 日期支持 Excel 日期、YYYY-MM-DD、YYYY/MM/DD 和美式 MM/DD/YYYY。其他格式请先转换，不自动猜测日/月顺序。
- 账户类型与列名的归因窗口必须一致；统一列名默认依账户类型采用 SP 卖家 7 天、供应商 14 天。来源中的多账户、多站点、不同币种和时区不能混合导入。
- 生成日期初值来自文件时间，需核对真实生成日期。归因窗口结束后仍可能发生报表修订。
- 重复文件跳过；相同维度和日期的较新记录更新旧记录。未出现在新文件的旧行保留，不自动视为删除。日期相交而粒度不同的记录拒绝合并。
- 广告组由用户明确选择，按整组分析；不自动把多 ASIN 广告组的成绩分配到当前商品。不同报表视角不能相加。

首次对接实际报表时，请检查字段映射与数值格式。测试覆盖合成的新旧、中英文报表，尚未使用你的实际广告导出文件作逐列核对。

## 分析方式

- 商品综合分析、单词分析、操作前后复盘。默认最近 30 天，结束于最新排名日期；可选 7 天或自定义 1–366 天，并比较前一个等长区间。
- CTR、CPC、购买率、ACOS、ROAS 与排名变化由本机计算。分母为零、缺失记录、报表未出现不能假装成有效的零。
- 每份报告包含事实、推测、建议核查和数据限制。结论引用证据编号，点击可查看原文件/日期；模型引用不存在编号时整份结果被拒绝。
- 超过 100 条证据时，本机按广告花费或排名变动幅度优先选取，并在预览中显示限制。需要完整细查时按关键词分别分析。
- 目标 ACOS 按商品选填。没有利润资料不判断盈利，没有全店销售不计算 TACOS。广告组整体指标不能直接判断某个商品是否达标。
- 备注默认不发送；操作复盘中可显式选择发送一条备注。前后比较只能说明观察到的变化，不能证明调价、广告或 Listing 修改导致了变化。
- 模型输出作为普通文本显示，不执行脚本，不操作广告账户。证据编号校验无法证明每一句解释正确，仍需人工核对。

## 安全与数据位置

业务数据保存在当前 Windows 用户的 `%APPDATA%\KeywordRankAI` 中，与原网页版及旧桌面版分开。排名数据使用独立 Electron 浏览器存储；广告、历史报告和偏好保存在此目录的本地 JSON 中。

- 密钥仅在专用设置窗口输入，主界面没有读取完整密钥的接口。持久保存使用 Electron safeStorage / Windows 系统加密；不可用时只允许会话使用。
- API 地址仅支持 HTTPS 公网目的地、443 端口。拒绝内网及特殊地址；每次请求校验 DNS 并固定解析结果；不跟随重定向。格式为完整 `/chat/completions` 地址或平台提供的 `/v1` 基地址。
- 不支持直接使用 HTTP / localhost 模型服务，也不支持只提供 Anthropic Messages 或 Responses 协议的接口。不要关闭 TLS 校验来解决连接问题。
- 同时只允许一个请求，120 秒超时；可取消，失败不自动重试。平台已收到的请求在取消或超时后仍可能计费。
- 商品和活动名称使用代号，原始文件、数据库、密钥和本地路径不进入 AI 请求。关键词与经营指标本身仍可能透露业务信息。
- 中转平台会接触提交的内容和用于该平台的密钥。请选择可信平台，核对其隐私、日志及数据留存说明。可以为本软件单独创建低额度密钥。
- 系统加密无法防止已控制当前 Windows 账户的恶意程序。发布包不包含任何共用密钥，也不提供自动广告调整。

排名备份通过原“工具文件夹”导出。广告和分析记录通过“广告报表 → 导出广告与分析备份”导出，两类备份均不含密钥。分析历史最多保留最近 50 份成功报告。恢复广告备份前会单独保存恢复前副本。

首次发布未配置代码签名证书；可使用随包 SHA256 校验文件检查下载完整性。勿将系统用户数据目录与源码或发布包一起上传 GitHub。

## 开发与验证

从仓库根目录执行：

```text
npm run install:keyword-rank
npm run test:ai
npm run build:ai
npm --prefix apps/keyword-rank run start:ai
npm run dist:ai
```

独立入口为 `apps/keyword-rank/electron/ai/main.cjs`，生产包仅包含正式构建、空业务数据和必要运行依赖；不包含测试适配器。Electron 44 的开发运行时若未下载，可在应用目录执行 `node node_modules/electron/install.js`。

`tests/ai/electron-smoke.cjs` 在临时用户目录中测试 IPC、Windows 加密、模拟请求成功/失败/取消、报表导入、备份恢复；不会使用真实平台或真实密钥。可传入已打包 `app.asar` 内的主入口路径，检查实际打包文件。

`tests/ai/browser-fixture.cjs` 只用于本地渲染 QA，提供合成数据和模拟适配器。它的本地测试 HTTP 服务不属于发行程序。

发布前运行依赖审计、源码/构建/历史密钥扫描，确认空种子、配置文件和业务备份均不包含密钥，再生成压缩包。官方网页发行仍通过原 `release:web` / `verify:web` 流程构建验证。
