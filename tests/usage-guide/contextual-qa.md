## 修改

- 18 步教学逐步切换到实际页面，专题入口直接进入对应步骤。
- 展示看板管理关注词表单（含无流量关键词教学）、看板趋势浮窗、自然矩阵 ABA 浮窗、排名格详情、自然/SP 标注示例、对比矩阵与完整趋势、ABA月榜、ABA 导入、竞品设置、历史和备份面板。
- 标注示例只读，关注词示例禁止保存。退出恢复原页签、筛选、滚动位置；恢复的水平位置不再被“自动滚到最新日期”覆盖。
- 管理关注词使用独立 portal 和遮罩，层级高于放大看板，支持键盘焦点循环及 Esc 关闭。
- 看板趋势浮窗依据实际尺寸定位，避免超出屏幕底部。
- 移除恢复上周数据的按钮、确认界面和事件处理；保留正常 JSON 导出/导入及自动备份持久化逻辑。
- 移除每周广告关注词分析栏目、自然矩阵中的分析说明与数据接入；发布不再附带该分析的说明和 Skill 文件。已有业务数据不删除。
